# Practica Pull request CH 71

El objetivo de este repositorio es que se practique como crear un pull request desde un fork

## Instrucciones
1. Crear un fork del repositorio 
<img width="495" height="76" alt="image" src="https://github.com/user-attachments/assets/a87e7edd-7eb6-413a-806f-5ae3b4c00774" />
picandole en el boton que dice fork

2. Clonar el repositorio **asegurarse de usar la forma de ssh**

3. Crear un nuevo repositorio usando ``` git branch nombreRama```

4. En la nueva rama modificar el archivo nombres.txt con tu nombre y un apellido

5. Confirmar los cambios

6. Enviar los cambios a github usando ``` git push origin nombreRama```

7. Crear un pull request
